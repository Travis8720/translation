# 학생 통역 대화 사이트 (무료판: 중국어·일본어·영어)

번역은 **선생님 컴퓨터의 크롬 브라우저에 내장된 번역 기능**으로 처리합니다. 학생 휴대폰은 메시지를 보내고 받기만 합니다.
그래서 번역 API 키나 결제 카드가 필요 없고, 대화 내용이 번역 업체 서버로 가지 않습니다.

## 0단계: 먼저 확인 (5분)

선생님 컴퓨터에서 이것부터 확인하세요. 여기서 막히면 이 방식은 쓸 수 없습니다.

1. **컴퓨터용 크롬** 최신 버전인지 확인: 주소창에 `chrome://settings/help` 입력 → 버전 138 이상이어야 합니다.
2. 학교에서 관리하는 컴퓨터라면 관리자 정책으로 내장 AI 기능이 꺼져 있을 수 있습니다. 배포 후 첫 화면의 언어별 상태가 모두 "지원 안 됨"으로 나오면 이 경우입니다. 이때는 정보부장님이나 전산 담당께 문의하거나 개인 노트북을 쓰셔야 합니다.
3. 번역 모델을 처음 내려받을 때 저장공간과 인터넷이 필요합니다. 학교 와이파이가 느리면 첫 준비에 몇 분 걸릴 수 있습니다. 한 번 받으면 다음부터는 바로 됩니다.

## 1단계: Firebase (무료 요금제, 카드 불필요)

1. https://console.firebase.google.com 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 됨). 요금제는 기본값인 **Spark(무료)** 그대로 둡니다.
2. **Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)`
   - **프로덕션 모드**로 시작
3. Firestore의 **규칙** 탭에 `firestore.rules` 내용을 통째로 붙여넣고 **게시**
4. 프로젝트 설정(톱니바퀴) → **내 앱 → 웹(</>) 앱 추가** → 나오는 `firebaseConfig` 값을 `firebase-config.js` 에 붙여넣기

## 2단계: 사이트 올리기 (GitHub Pages, 무료)

1. https://github.com 가입 → 새 저장소(New repository) 만들기. 이름 예: `talk`. **Public** 으로 만듭니다 (무료 계정의 Pages는 공개 저장소에서만 됩니다).
2. **Add file → Upload files** 로 이 폴더 안의 파일을 전부 올리고 **Commit changes**
3. 저장소의 **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `(root)` → **Save**
4. 1~2분 뒤 `https://아이디.github.io/talk/` 주소가 생깁니다.

> 저장소가 공개되어도 괜찮습니다. 코드와 Firebase 연결 정보만 보이고, 대화 내용은 방 코드를 아는 사람만 볼 수 있게 규칙으로 막혀 있습니다.

## 3단계: 테스트

1. 선생님 컴퓨터 크롬에서 사이트 열기 → 언어별 상태 확인
2. **번역 준비하고 새 대화 시작** 클릭 (처음에는 모델을 내려받느라 시간이 걸립니다)
3. 휴대폰 카메라로 QR 찍기 → 언어 선택 → 메시지 보내기
4. 컴퓨터에 한국어 번역이 뜨는지, 답장이 휴대폰에 학생 언어로 뜨는지 확인
5. **대화 끝내고 기록 삭제** 를 누르면 학생 화면도 종료되는지 확인

## 알아둘 점

- **대화 중에는 선생님 컴퓨터의 이 창을 닫으면 안 됩니다.** 학생 메시지는 선생님 컴퓨터가 번역하기 때문에, 창이 닫혀 있으면 번역되지 않고 "번역 중…"으로 남습니다. 다시 열면 이어서 번역됩니다.
- 파일을 더블클릭해서 열면 동작하지 않습니다. 반드시 GitHub Pages 주소(https)로 여세요.
- 음성 입력은 안드로이드 크롬에서 가장 잘 되고, 아이폰은 안 될 수 있습니다. 안 되는 기기에서는 마이크 버튼이 숨겨집니다.
- 대화 기록은 **대화 끝내고 기록 삭제**를 눌러야 지워집니다.
- Firebase 무료 요금제는 하루 읽기·쓰기 횟수에 한도가 있습니다. 상담 몇 건 정도로는 넘기기 어렵지만, 한도를 넘으면 그날은 멈추고 요금이 청구되지는 않습니다.
